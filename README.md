Анапская косметика

Коммерческий сайт косметического бренда с каталогом товаров и корзиной.

Технологии:
 HTML5
 CSS3
 JavaScript
 CSS Grid
 Flexbox
 LocalStorage

Возможности:

 Адаптивная вёрстка
 Каталог товаров
 Фильтрация по категориям
 Карточки товаров
 Модальные окна
 Корзина
 Изменение количества товаров
 Расчёт стоимости
 Сохранение корзины в LocalStorage
 Ссылки на Ozon и другие магазины

Сайт создан с нуля на HTML, CSS и JavaScript без использования фреймворков.
