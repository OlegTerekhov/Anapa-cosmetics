Анапская косметика.
Коммерческий сайт косметического бренда с каталогом товаров и корзиной.
Технологии:
 HTML5, CSS3, Javascript, CSS grid, Flexbox, LocalStorage.
Возможности:
 Адаптивная верстка, каталог товаров, фильтрация, карточки товаров, модальные окна, корзина,
 расчет стоимости, сохранение корзины в LocalStorage.
Сайт создан с нуля на HTML, CSS и Javascript без фреймворков.
