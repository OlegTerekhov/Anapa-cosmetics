Анапская косметика

Коммерческий сайт косметического бренда с каталогом товаров и корзиной.

Технологии: HTML5, CSS3, JavaScript, CSS Grid, Flexbox, LocalStorage.

Возможности: адаптивная вёрстка, каталог товаров, фильтрация, карточки товаров, модальные окна, корзина, расчёт стоимости, сохранение корзины в LocalStorage.

Сайт создан с нуля на HTML, CSS и JavaScript без фреймворков
