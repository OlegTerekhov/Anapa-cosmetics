# Анапская косметика

Коммерческий веб-сайт косметического бренда с каталогом товаров, интерактивными карточками и корзиной.

## Технологии

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* CSS Grid / Flexbox
* LocalStorage
* Responsive Design

## Реализовано

* Адаптивный дизайн для компьютеров, планшетов и мобильных устройств
* Современная навигация и hero-секция
* Динамический каталог товаров
* Категории товаров
* Карточки товаров с описанием, ценой, объёмом и артикулом
* Модальные окна с подробной информацией о товаре
* Добавление товаров в корзину
* Изменение количества товаров
* Удаление товаров из корзины
* Автоматический расчёт общей стоимости
* Сохранение корзины в LocalStorage
* Интерактивные уведомления
* Hover-анимации и визуальные эффекты
* Ссылки на внешние магазины и Ozon
* Контактный блок и информация о фирменном магазине
* Демонстрационная функция оформления заказа

## Особенности

Каталог товаров и карточки формируются динамически с помощью JavaScript. Данные о товарах хранятся в массиве объектов, а состояние корзины сохраняется в браузере с помощью LocalStorage.

## Проект

Сайт создан с нуля на HTML, CSS и JavaScript без использования frontend-фреймворков.
