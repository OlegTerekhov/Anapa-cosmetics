Анапская косметика

Коммерческий сайт косметического бренда с каталогом товаров и корзиной

Технологии:
HTML5, CSS3, JavaScript, CSS Grid, Flexbox, LocalStorage.

Возможности:
Адаптивная вёрстка, каталог товаров, фильтрация по категориям, карточки товаров, модальные окна, корзина, изменение количества товаров, расчёт стоимости, сохранение корзины в LocalStorage, ссылки на Ozon и другие магазины.

Сайт создан с нуля на HTML, CSS и JavaScript без использования фреймворков.
