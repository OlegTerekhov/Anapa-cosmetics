# Анапская косметика

Коммерческий веб-сайт косметического бренда с каталогом товаров, интерактивными карточками, корзиной и демонстрационной функцией оформления заказа.

## Технологии

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* CSS Grid
* Flexbox
* LocalStorage
* Responsive Design
* DOM Manipulation
* CSS Animations

## Реализовано

* Адаптивный дизайн для компьютеров, планшетов и мобильных устройств
* Современная навигация
* Hero-секция
* Динамический каталог товаров
* Фильтрация товаров по категориям
* Карточки товаров
* Подробная информация о товарах
* Модальное окно товара
* Добавление товаров в корзину
* Изменение количества товара
* Удаление товаров из корзины
* Автоматический расчёт общей стоимости
* Счётчик товаров в корзине
* Сохранение корзины в LocalStorage
* Интерактивные уведомления
* Hover-анимации и визуальные эффекты
* Плавная прокрутка по разделам
* Ссылки на внешние магазины и Ozon
* Контактный блок
* Информация о фирменном магазине
* Демонстрационная функция оформления заказа

## JavaScript

Каталог товаров формируется динамически с помощью JavaScript.

Данные о товарах хранятся в массиве объектов. Для каждого товара используются отдельные параметры:

* название;
* категория;
* описание;
* цена;
* объём;
* артикул;
* изображение;
* ссылка на внешний магазин.

JavaScript отвечает за:

* формирование каталога;
* фильтрацию товаров;
* открытие карточки товара;
* работу модальных окон;
* добавление товаров в корзину;
* изменение количества товаров;
* удаление товаров;
* подсчёт количества товаров;
* расчёт общей стоимости;
* сохранение состояния корзины;
* отображение уведомлений;
* обработку пользовательских действий.

## LocalStorage

Состояние корзины сохраняется в браузере с помощью `LocalStorage`.

Благодаря этому добавленные товары остаются в корзине после обновления страницы.

Используемый ключ:

```javascript
anapa_cart
```

## Адаптивность

Интерфейс адаптирован под различные размеры экранов с помощью CSS Media Queries.

Предусмотрены отдельные варианты отображения для:

* компьютеров;
* планшетов;
* мобильных устройств.

Размеры и расположение элементов интерфейса изменяются в зависимости от ширины экрана.

## Особенности проекта

Сайт создан с нуля на чистом HTML, CSS и JavaScript без использования frontend-фреймворков.

Интерактивная часть реализована на Vanilla JavaScript.

Каталог товаров формируется программно из массива данных, поэтому товары можно добавлять и изменять без необходимости вручную создавать каждую HTML-карточку.

Корзина работает на стороне клиента и сохраняет своё состояние в браузере.

## Ограничения

Проект является клиентским демонстрационным веб-сайтом.

В нём не используются:

* backend;
* база данных;
* авторизация пользователей;
* серверная обработка заказов;
* реальная платёжная система;
* API для загрузки каталога.

Оформление заказа является демонстрационной функцией интерфейса.
