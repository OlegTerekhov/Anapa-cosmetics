# Anapa Cosmetics

Адаптивный сайт косметического бренда «Анапская косметика» с каталогом товаров и корзиной.

**Демо:** [olegterekhov.github.io/Anapa-cosmetics](https://olegterekhov.github.io/Anapa-cosmetics/)

## О проекте

Коммерческий сайт для бренда натуральной косметики. Реализован каталог товаров с фильтрацией, карточки товаров, корзина с подсчётом стоимости и сохранением данных.

## Функционал

- Адаптивная вёрстка (мобильный, планшет, десктоп)
- Каталог товаров
- Фильтрация товаров
- Карточки товаров
- Модальные окна
- Корзина с расчётом стоимости
- Сохранение корзины в LocalStorage

## Технологии

- HTML5
- CSS3 (Flexbox, CSS Grid)
- JavaScript (Vanilla)
- LocalStorage

## Как запустить

Просто откройте файл `index.html` в браузере.
